# Design System Document

## Brand & Style
This design system adopts a **vibrant, high-contrast modern** style tailored for immersive dark-mode applications. It combines neon-inspired electric accents with deep slate-navy neutrals to evoke a futuristic, energetic, and highly focused user experience.

## Colors
The color system is optimized for dark mode interfaces:
- **Primary:** `#7dd3fc` (Electric sky blue)
- **Secondary:** `#88b4cc` (Slate blue)
- **Tertiary:** `#c8a0f0` (Soft lavender)
- **Neutral:** `#1a2438` (Deep navy)

## Typography
Uses **Inter** exclusively across all headlines, body text, and labels, providing clean legibility and modern geometric proportions.

## Layout & Spacing
Built on a consistent spacing multiplier (`2`) providing reliable grid gutters, margins, and component padding scales.

## Elevation & Depth
Elevation utilizes tonal surface layering and low-contrast outlines over the dark background palette.

## Shapes
Rounded aesthetic (Level 2) featuring 0.5rem base radius for friendly, modern interactive surfaces.

## Components
Includes standardized buttons, cards, input fields, chips, and navigational lists styled to match the vibrant dark aesthetic.

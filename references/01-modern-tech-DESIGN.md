# Design System

## Brand & Style
The brand identity uses a modern, clean, and professional aesthetic ("tonal_spot" variant). The UI is designed to feel precise, accessible, and balanced, prioritizing clarity and content readability while maintaining a polished, contemporary feel.

## Colors
The color palette is built around a vibrant indigo primary (`#6366f1`), complemented by a slate secondary (`#6c6e7e`), a rich violet tertiary (`#7c3aed`), and a balanced neutral tone (`#585a68`). The interface defaults to a clean `light` mode.

## Typography
The typography stack relies exclusively on **Plus Jakarta Sans** across all levels (headlines, body, and labels). This ensures a cohesive, highly readable, and geometric appearance suited for modern web applications.

## Layout & Spacing
A structured fluid grid system is used with standard 1rem gutters and 1.5rem outer margins. The spacing scale (`space-xs` through `space-xl`) provides consistent rhythm for component padding and element gaps.

## Elevation & Depth
Visual hierarchy is maintained primarily through tonal surface layering and soft, diffused shadows that provide subtle depth without cluttering the interface.

## Shapes
The roundedness level is set to `2` (Rounded), meaning standard UI elements feature a friendly 0.5rem corner radius, with larger containers scaling up gracefully.

## Components
Components leverage the primary indigo color for key actions, secondary slate tones for supporting elements, and standard rounded corners for a modern, approachable feel.
